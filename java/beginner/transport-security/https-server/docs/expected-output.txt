ONE. An HTTPS request that is checked.
  the shop's certificate is trusted by the client and matches the name shop.example.test
  the request is answered: 200 cart: 2 items, over TLSv1.3
  security headers present: 5 of 5, including Strict-Transport-Security
  the client checked three things: that the certificate is one it trusts, that it names the shop, and that it is current
TWO. Plain HTTP only redirects.
  a request to the plain port gets: 301 moved permanently
  it points to an https address: true
  the plain answer carries no HSTS header: true  (browsers ignore HSTS sent over HTTP)
  the first request itself crossed the network in the clear  <- THE FIRST VISIT IS STILL EXPOSED; HSTS protects the later ones
THREE. A cookie that stays on HTTPS.
  the login sets: session=...; Secure; HttpOnly; SameSite=Lax; Path=/
  asking again over https, the cookie is sent: cookie received
  asking over plain http, the cookie is sent: false  (the Secure flag keeps it off plain connections)
  a cookie without the Secure flag, asked over plain http, is sent: true  <- A LEAK
FOUR. What the client refuses.
  a server with the right name and a certificate nobody trusts: refused (SSLHandshakeException)
  the right certificate, reached under another name: refused (SSLHandshakeException)
  a client that demands TLS 1.3, and a server that offers only 1.2: refused (SSLHandshakeException)
  the same server, a client that also allows 1.2: ok (TLSv1.2)
  allowing the older version is a choice the client makes, and it is what a downgrade attack asks for
FIVE. Scoring a shop from outside.
  the careful shop scores 5 of 5
  the careless shop, the certificate is trusted and matches the host name: yes
  the careless shop, TLS 1.3 is accepted: no
  the careless shop, plain HTTP redirects to HTTPS: no
  the careless shop, HSTS lasts at least a year: no
  the careless shop, the session cookie is Secure, HttpOnly and SameSite: no
  the careless shop scores 1 of 5: a valid certificate is only the first item
  a padlock proves who the server is and that the connection is private; it says nothing about the rest of the setup
