ONE. The same page, with and without Spring Security's header writers.
  a customer asks for /products over plain HTTP on this machine
  the store with headers switched off scores 0 of 5 (missing or weak: Strict-Transport-Security, Content-Security-Policy, X-Content-Type-Options, X-Frame-Options, Referrer-Policy)
  the hardened store scores 4 of 5 (missing or weak: Strict-Transport-Security)
  the framework leaves out Strict-Transport-Security on plain HTTP on purpose: a browser must ignore it there, so sending it would only mislead
TWO. The same page behind a proxy that ends HTTPS.
  the proxy adds X-Forwarded-Proto: https, and the hardened store scores 5 of 5
  Strict-Transport-Security: max-age=31536000 ; includeSubDomains
  Content-Security-Policy: default-src 'self'; frame-ancestors 'none'
  this trust in a forwarded header is safe only because the store listens on the loopback interface and only the proxy can reach it
THREE. The cookie that carries the cart's session.
  default store: cookie JSESSIONID, problems: 2
    - no Secure: it is also sent over plain HTTP
    - no SameSite: other sites can trigger requests that carry it
  hardened store: cookie JSESSIONID, problems: 0
  three properties turn the safe attributes on: cookie.http-only, cookie.secure and cookie.same-site
FOUR. A line break inside a header.
  the customer's search text, with a line break and a second header, is put in X-Echo
  the answer contains a second header with the attacker's cookie: false
  the server refused to write a header with a line break: status 500, and no X-Echo header at all: true
  a request with a space in a header name gets status 400
  the container turns the attack into an error, and the code must still never write customer text into a header unchecked
FIVE. Limits on the size of a request.
  a request with a 4000-character header: default store answers 200, hardened store (limit 1KB) answers 400
  a small limit keeps one customer from making the server read and hold megabytes, and the limit must still be high enough for real cookies
