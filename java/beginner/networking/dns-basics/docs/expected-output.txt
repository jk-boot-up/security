ONE. A DNS message, byte by byte.
  THE QUESTION (34 bytes):
    header   abcd 0100 0001 0000 0000 0000
    name     04 73686f70 07 6578616d706c65 03 636f6d 00
    type     0001 = A, an IPv4 address
    class    0001 = IN, the internet
  THE ANSWER (50 bytes):
    header   abcd 8180 0001 0001 0000 0000
    question the same 22 bytes as above
    name     c00c = a pointer to byte 12
    type     0001  class 0001
    ttl      0000012c = 300 seconds
    address  0004 cb00710a = 203.0.113.10
  without the pointer the answer would be 66 bytes, not 50
  no sender in it: only the id and question must match
TWO. The cache and the time to live.
  THE ANSWER (second 0):
    shop.example.com  203.0.113.10  ttl 300
    kept until 0 + min(300, cap 3600) = second 300
  LATER QUESTIONS:
    second 100  from the cache  203.0.113.10  upstream 1
    second 299  from the cache  203.0.113.10  upstream 1
    second 300  expired, asked again          upstream 2
  a false answer goes to every customer until it expires
THREE. A real exchange over UDP on this machine.
  THE QUERY (one datagram, 34 bytes):
    id 1234, asks for shop.example.com
    seen on the path: .4...........shop.example.com.....
    name readable: true  <- THE PATH SEES IT
  THE RESPONSE (one datagram, 50 bytes):
    arrived: true, repeats id 1234: true
    says 203.0.113.10
  no connection and no signature on the reply
FOUR. Cache poisoning by guessing.
  THE ATTACK: up to 1000 forged answers, each says 192.0.2.66
  BEFORE THE FIX: ids count up, every query from port 53
    last id seen 4000, so the guess is id 4001, port 53
    after 1 forged answer the cache says 192.0.2.66  <- POISONED
  AFTER THE FIX: id and port from a keyed hash of a counter
    HMAC-SHA-256(secret, 2) = c56a 8cedc967 79cf64f4 ...
    id    first 2 bytes c56a = 50538
    port  1024 + (8cedc967 mod 64512) = 30055
    after 1000 forged answers the cache says nothing
  1 of 65536 ids x 64512 ports = 4227858432 pairs
  1000 guesses hit about 1 time in 4227858
FIVE. How long a false answer lives, and what stops it.
  THE FALSE ANSWER: 192.0.2.66, keep it 86400 seconds (a day)
  BEFORE THE FIX: cap 86400 (a day)
    kept until min(86400, 86400) = second 86400
    still believed after 2 hours (second 7200): true
  AFTER THE FIX: cap 3600 (an hour)
    kept until min(86400, 3600) = second 3600
    still believed after 2 hours (second 7200): false
  WHAT ELSE STOPS IT (described here, not run):
    DNSSEC: a forged answer fails the signature check
    DNS over TLS or HTTPS: hides the questions on the path
    TLS: the certificate must name shop.example.com
