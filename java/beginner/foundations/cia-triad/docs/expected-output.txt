THREE. Integrity: every order is saved with a seal.
  BEFORE SEALING (the inputs):
    order text  O-101|Maya Rao|Laptop|12 Palm Street|1200
    key         demo-only-secret-not-for-real-use
  AFTER SEALING (HMAC-SHA256 of the text, with the key):
    seal        701017e4 0f4b5c72 35d9a6a2 72a14cb4
                34ef287b b2ca343b acee4afa a10f3d55
  the seal is 32 bytes, written as 64 hex characters
  storage keeps the order and its seal side by side
FOUR. How the seal is made, step by step.
  STEP 1. PAD THE KEY WITH ZERO BYTES TO 64 BYTES:
    key         33 bytes + 31 zero bytes = 64 bytes
    as hex      64656d6f 2d6f6e6c ... 00000000
  STEP 2. INNER HASH = SHA-256(key xor 36 + the text):
    key xor 36  52535b59 1b59585a ... 36363636
    inner       3854d249 8b389b27 4d465bbb ce170a34
                3c9fd86e 23d72511 2fc3ed2b 4bd1ca0b
  STEP 3. SEAL = SHA-256(key xor 5c + inner hash):
    key xor 5c  38393133 71333230 ... 5c5c5c5c
    seal        701017e4 0f4b5c72 35d9a6a2 72a14cb4
                34ef287b b2ca343b acee4afa a10f3d55
    the same seal Java's Mac gave in act three: true
FIVE. A change behind the application is caught.
  BEFORE THE EDIT (in storage):
    order  O-101|Maya Rao|Laptop|12 Palm Street|1200
    seal   701017e4 0f4b5c72 ...
  AFTER THE EDIT (mallory, directly in storage):
    order  O-101|Maya Rao|Laptop|12 Palm Street|12
    seal   701017e4 0f4b5c72 ...  (left as it was)
  ANA READS O-101 (the seal is worked out again):
    new seal  3513c4ae 562fdd03 ...
    matches the stored seal: false
    refused, O-101 does not match its seal  <- DETECTED
  ana reads O-102 (untouched): Tom Lee, Headphones, $80
SIX. Availability: one client cannot use up the whole server.
  THE REQUESTS (one tick):
    100 checkouts from the bot, then 1 from maya
    the server can do 10 requests in one tick
  HOW THE LIMIT DECIDES (3 per client per tick):
    bot   request 1   count 1, at most 3: allowed
    bot   request 2   count 2, at most 3: allowed
    bot   request 3   count 3, at most 3: allowed
    bot   request 4   count 4, over 3: refused
    bot   requests 5 to 100: refused the same way
    maya  request 1   count 1, at most 3: allowed
  THE RESULTS:
    without the limit: bot 10 served, maya refused
    with the limit:    bot 3 served, 97 refused
                       maya 1 served  <- SERVED
