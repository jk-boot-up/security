## Title

Threats and Risk Explained in Java

## Description

Threats and risk in Java: a threat is who or what could do harm, a vulnerability is the weakness it would use, an asset is what gets harmed, and a risk is how likely and how bad it is. Explained with an online store, like a house owner walking round every door and window before buying locks. We count the store's attack surface, score seven risks as likelihood times impact, rank them, spend a fixed budget where it removes the most risk, and finish with the cost: a risk score is a judgment, so two sensible reviewers can rank the same list differently.

Source code and notes: github.com/jk-boot-up/security/tree/main/java/beginner/foundations/threats-and-risk
