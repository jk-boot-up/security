# Prerequisites

## Required

- Java basics: classes, records, enums, lists and streams
- The three promises from the previous project, cia-triad, are helpful but not required

## Explicitly not required

- Any security tools or frameworks
- Networking, web frameworks or databases
- Mathematics beyond multiplication

## What you will need

- A JDK is optional: Gradle finds or downloads JDK 25 by itself. Everything else comes with the Gradle wrapper.
- About an hour for the session guide.
