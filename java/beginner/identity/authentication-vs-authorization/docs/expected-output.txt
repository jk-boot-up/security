ONE. The first version, with no checks.
  nobody refunds O-1: 200 OK  <- NOBODY ASKED WHO
  nobody views O-1: 200 OK
TWO. Authentication: finding out who is asking.
  ben logs in with a wrong password: rejected
  ben logs in with his password: session tok-1
  request with no token: 401 UNAUTHENTICATED
  request with a made-up token tok-99: 401 UNAUTHENTICATED
  request with ben's token: 200 OK
THREE. Authenticated is not the same as authorized.
  ben, a customer, refunds O-1: 200 OK  <- LOGGED IN, SO ALLOWED
  ben views ana's order O-1: 200 OK  <- NOT HIS ORDER
FOUR. Authorization: what may this person do?
  no token refunds O-1: 401 UNAUTHENTICATED
  ben refunds O-1: 403 FORBIDDEN
  ben views ana's order O-1: 403 FORBIDDEN
  ben views his own order O-2: 200 OK
  sam, from support, views O-1: 200 OK
  sam refunds O-1: 200 OK
  ana cancels ben's order O-2: 403 FORBIDDEN
  alex, an admin, cancels O-2: 200 OK
FIVE. The bill: sessions expire, and roles go stale.
  sam logs in at tick 0: tok-1, good for 3 ticks
  at tick 4 sam refunds O-1: 401 UNAUTHENTICATED (expired)
  sam logs in, then alex demotes sam to CUSTOMER
  sam refunds with the role copied at login: 200 OK  <- STALE ROLE
  sam refunds with the role looked up each time: 403 FORBIDDEN
  role lookups for that one request: 1
