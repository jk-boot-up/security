# Prerequisites

## Required

- Java basics: classes, records, enums, interfaces, and a little streams
- The idea of a web request and a response with a status code is helpful, but the demo needs no web server

## Explicitly not required

- A web framework, a database or a real login page
- Cryptography: the password hash is used as a black box and explained in the password-hashing project
- Tokens such as JWT: sessions here are plain numbered tokens

## What you will need

- A JDK is optional: Gradle finds or downloads JDK 25 by itself. Everything else comes with the Gradle wrapper.
- About an hour for the session guide.
