Learning Path: the order to follow

Work through the projects top to bottom. Each one builds on the ones before it, and a project that uses a tool or framework comes straight after the plain version, so you see the idea first and the tool second.

Every project has the same parts: a README, runnable Java 25 code with tests, diagrams, a threat model, an animated walkthrough and a narrated video script. Start with the project's README, run ./gradlew run, then read its docs/ folder.

Legend: Plain means written with the JDK only. With tools means the same idea using a library, framework or local tool. Projects marked planned are not built yet.
