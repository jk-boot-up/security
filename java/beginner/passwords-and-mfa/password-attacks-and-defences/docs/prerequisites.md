# Prerequisites

## Required

- Java basics: classes, records, enums and maps
- The password-hashing project is helpful: this one is about what happens around the password check

## Explicitly not required

- Web frameworks or real networking: the login is a method call
- How a second factor is implemented: the totp project covers that
- Any attack tooling: the attacks are short scripts in the project itself

## What you will need

- A JDK is optional: Gradle finds or downloads JDK 25 by itself. Everything else comes with the Gradle wrapper.
- About an hour for the session guide.
