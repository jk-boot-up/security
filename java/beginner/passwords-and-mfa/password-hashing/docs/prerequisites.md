# Prerequisites

## Required

- Java basics: classes, records, interfaces and maps
- The idea of a hash as a one-way function is explained here, so no cryptography is assumed

## Explicitly not required

- Mathematics behind hash functions
- A web framework or a database
- Knowledge of bcrypt or Argon2: they are mentioned, and the with-spring-security-crypto project uses them

## What you will need

- A JDK is optional: Gradle finds or downloads JDK 25 by itself. Everything else comes with the Gradle wrapper.
- About an hour for the session guide.
