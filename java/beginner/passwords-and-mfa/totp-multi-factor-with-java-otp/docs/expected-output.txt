ONE. The library's codes, checked against the standard.
  BEFORE: THE INPUTS
    key       12345678901234567890  (the RFC test key)
    times     0, 30, 60, 90 and 59 seconds since 1970
  AFTER: THE LIBRARY'S CODES
    time 0    step 0   755224
    time 30   step 1   287082
    time 60   step 2   359152
    time 90   step 3   969429
    time 59   step 1   287082  <- THE VALUE IN RFC 6238
TWO. How the code at time 59 is made, step by step.
  STEP 1. THE TIME STEP = 59 / 30, AS 8 BYTES:
    step      1
    counter   00000000 00000001
  STEP 2. HMAC-SHA1(key, counter) = 20 BYTES:
    hmac      75a48a19 d4cbe100 644e8ac1 397eea74 7a2d33ab
  STEP 3. TAKE 4 BYTES, FROM THE LAST HALF-BYTE ON:
    last      ab, so offset 11
    4 bytes   c1397eea
  STEP 4. DROP THE TOP BIT, KEEP THE LAST 6 DIGITS:
    number    1094287082
    code      287082
  the same code the library gave: true
THREE. What the library checks, and what the bank adds.
  BEFORE: THE LIBRARY ALONE
    287082 at time 59, step 1: true
    287082 at time 40, step 1: true
    287082 at time 65, step 2: false  <- ONE STEP ONLY
  AFTER: THE BANK'S WINDOW OF 1 STEP EITHER SIDE
    287082 at time 65, step 2: OK
    287082 at time 95, step 3: WRONG_CODE
FOUR. Other hashes and longer codes.
  BEFORE: THE SETTINGS, AT TIME 59
    SHA-1     20-byte key, 8 digits
    SHA-256   32-byte key, 8 digits
    SHA-512   64-byte key, 8 digits
  AFTER: THE CODES
    SHA-1     94287082
    SHA-256   46119246
    SHA-512   90693936
  all three are the values of RFC 6238
  many authenticator apps take only SHA-1, 6 digits, 30 seconds
FIVE. Giving the secret to the phone.
  BEFORE: WHAT THE BANK PUTS IN
    issuer    Example Bank
    account   dana@example.com
    secret    12345678901234567890  (20 bytes)
    settings  SHA1, 6 digits, 30 seconds
  AFTER: THE TEXT IN THE QR CODE
    otpauth://totp/Example%20Bank:dana%40example.com
      ?secret=GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ
      &issuer=Example%20Bank
      &algorithm=SHA1&digits=6&period=30
  Base32: 20 bytes = 160 bits = 32 letters of 5 bits each
  the app keeps the secret: show it once, in private
SIX. The bill: what the library does not do.
  BEFORE THE FIX: THE LIBRARY ALONE
    login at time 59 with 287082: OK
    login at time 64 with 287082: OK  <- USED TWICE
  AFTER THE FIX: THE BANK REMEMBERS THE LAST STEP
    login at time 59 with 287082: OK
    login at time 64 with 287082: REPLAYED
  still the bank's: secret storage, wrong-code counts,
