TWO. How a request is matched.
  THE POLICY AS WRITTEN (exporter, the S3 part):
    Allow s3:ListBucket on shop-reports
    Allow s3:GetObject on shop-reports/*
  THE REQUESTS (action on resource, then the decision):
    s3:GetObject on shop-reports/q3.csv    ALLOW
    s3:GetObject on shop-secrets/keys.pem  IMPLICIT_DENY
    s3:ListBucket on shop-reports          ALLOW
    s3:ListBucket on shop-reports/q3.csv   IMPLICIT_DENY
    s3:GetObject on shop-reports           IMPLICIT_DENY
    s3:getobject on shop-reports/q3.csv    ALLOW
  THE PATTERN s3:Get* (a star matches any letters):
    s3:GetObject  true
    s3:PutObject  false
  /* means the files in the bucket, not the bucket itself
  no statement matches: denied by default (IMPLICIT_DENY)
THREE. A deny beats every allow.
  THE POLICY AS WRITTEN (admin_with_deny):
    Allow * on *
    Deny s3:*, kms:* on shop-secrets/*, shop-secrets, key/*
  THE REQUESTS (action on resource, then the decision):
    s3:GetObject on shop-secrets/keys.pem  EXPLICIT_DENY
    kms:Decrypt on key/shop                EXPLICIT_DENY
    s3:PutObject on shop-reports/q3.csv    ALLOW
  THE SAME STATEMENTS IN THE OPPOSITE ORDER:
    the same answer for all 25 things: true
  THE COUNT (what a stolen key reaches):
    without the deny  25 of 25
    with the deny     20 of 25  <- STILL 20 OPEN

FIVE. A linter, and the way to more power.
  THE FINDINGS (the linter reads the text of each policy):
    wildcard         ACTION_STAR 1, RESOURCE_STAR 1
    exporter         none
    admin_with_deny  ACTION_STAR 1, RESOURCE_STAR 1
    boundary         RESOURCE_STAR 1
    deployer         RESOURCE_STAR 1, ESCALATION 1
  THE DEPLOYER AS WRITTEN:
    Allow lambda:InvokeFunction, lambda:CreateFunction

    Allow iam:PassRole on *
    a stolen key reaches 3 of 25: it looks small
  THE WAY TO MORE POWER (three steps):
    1. iam:PassRole on *: hand any role to a function
    2. lambda:CreateFunction: make checkout with that role
    3. lambda:InvokeFunction: run code as that role
  so read the policy as well as counting it
