    orders     read  write  delete
    customers  read  write  delete
    payments   read  write
    refunds    create  approve
    inventory  read  write
    reports    read
    secrets    read  write
  THE ROLES (what each one allows):
    admin      15 of 15  *
    support    3 of 15   orders:read customers:read refunds:create
    warehouse  3 of 15   inventory:read inventory:write orders:read
    finance    3 of 15   payments:read refunds:approve reports:read

  THE CHECK, STATEMENT BY STATEMENT:
    allow orders:read     does not match
    allow customers:read  does not match

  THE REQUEST: an admin with deny secrets:* asks for secrets:read
  THE CHECK, STATEMENT BY STATEMENT:
    allow *               matches: allowed, unless a deny matches
    deny secrets:*        matches: a deny, which wins
  THE DECISION: DENY_EXPLICIT  <- A DENY BEATS ANY ALLOW
