# Prerequisites

## Required

- Java basics
- The plain symmetric-encryption project, or at least what AES-GCM, a nonce and a tag are

## Explicitly not required

- Protocol buffers: Tink uses them internally
- A key management service: the master key is a second demo keyset
- Android or Google Cloud

## What you will need

- A JDK is optional: Gradle finds or downloads JDK 25 by itself. Everything else comes with the Gradle wrapper.
- About an hour for the session guide.
