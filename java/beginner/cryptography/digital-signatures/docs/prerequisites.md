# Prerequisites

## Required

- Java basics
- The hashing-and-integrity project, which ends by asking for exactly this, and the asymmetric-encryption project's idea of a key pair

## Explicitly not required

- The mathematics of elliptic curves
- Certificates: they come next
- Any library: the JDK has Ed25519

## What you will need

- A JDK is optional: Gradle finds or downloads JDK 25 by itself. Everything else comes with the Gradle wrapper.
- About an hour for the session guide.
