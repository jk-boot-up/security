# Prerequisites

## Required

- Java basics
- The plain symmetric-encryption project, or at least what a key, a nonce and AES-GCM are

## Explicitly not required

- The mathematics of RSA or elliptic curves
- Certificates or TLS: they come later in the track
- Prime numbers: the project never mentions one

## What you will need

- A JDK is optional: Gradle finds or downloads JDK 25 by itself. Everything else comes with the Gradle wrapper.
- About an hour for the session guide.
