ONE. A checksum for accidents.
  BEFORE THE CHANGE (the invoice as stored):
    invoice    INV-1001|ana|Laptop|1200
    CRC-32     a7c21715
  AFTER AN ACCIDENT (one bit flips on the disk):
    invoice    INV-1001|ana|Laptop|1201
    CRC-32     d0c52783  <- DOES NOT MATCH: DETECTED
  AFTER AN ATTACK (amount changed, a new CRC stored):
    invoice    INV-1001|ana|Laptop|12
    CRC-32     5e22dd78  <- MATCHES: THE CHECK PASSES
  a CRC has no secret, so it only guards against accidents
TWO. A cryptographic hash: SHA-256.
  the standard's test: abc gives ba7816bf8f01...  <- AS PUBLISHED
  BEFORE HASHING (two invoices, one digit apart):
    invoice 1  INV-1001|ana|Laptop|1200
    invoice 2  INV-1001|ana|Laptop|1201
  AFTER HASHING (32 bytes each, 64 hex digits):
    hash 1     87822981 3e30109f 57e2b8a1 b9c9a200
               6ddaf4e7 98dd4671 96c03e30 61ef4d05
    hash 2     7da712a1 2a1ccb18 171aa604 13055973
               18afaeda 54a6bc58 b1d4d06b f097868f
  62 of the 64 hex digits differ, 134 of the 256 bits: about half
  any input, a line or a whole book: always 64 hex digits

FOUR. A keyed hash: HMAC-SHA-256.
  BEFORE TAGGING (the inputs):
    key        demo-only-invoice-key-not-for-real-use
    invoice    INV-1001|ana|Laptop|1200
    as bytes   00000008 494e562d 31303031 00000003
               616e6100 0000064c 6170746f 70000000
               04313230 30
  AFTER TAGGING (the tag, 32 bytes):
    tag        54916ce1 1158db43 ccd2c678 b0fc1e05
               45498b8e 0b32f14f c7085d72 e7427d98
  THE CHECKS:
    the invoice with its tag            OK
    amount changed to 12, old tag       BAD_TAG
    a plain SHA-256 as the tag          BAD_TAG
    HMAC made with a guessed key        BAD_TAG
  without the key, no tag the service accepts can be made
FIVE. How the tag is made, step by step.
  BEFORE: THE KEY, PADDED WITH ZEROS TO 64 BYTES:
    key        64656d6f 2d6f6e6c 792d696e 766f6963 ...
  STEP 1. INNER KEY = KEY XOR 36 36 36 ...:
    inner key  52535b59 1b59585a 4f1b5f58 40595f55 ...
  STEP 2. INNER HASH = SHA-256(inner key + bytes):
    inner hash 5bd27bbf 3dd49cf5 a8c808cd f7c9cde5
               03fc9d14 3818cffd b6cf7f4e fd08142e
  STEP 3. OUTER KEY = KEY XOR 5c 5c 5c ...:
    outer key  38393133 71333230 25713532 2a33353f ...
  STEP 4. TAG = SHA-256(outer key + inner hash):
    tag        54916ce1 1158db43 ccd2c678 b0fc1e05
               45498b8e 0b32f14f c7085d72 e7427d98
  AFTER: the same tag Java's Mac gave in act four: true
