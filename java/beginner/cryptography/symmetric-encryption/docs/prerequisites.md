# Prerequisites

## Required

- Java basics: classes, records, arrays and exceptions
- The hashing-and-integrity project is helpful, since GCM's tag is a close relative of HMAC

## Explicitly not required

- How AES works inside: it is used from the JDK
- Any mathematics beyond XOR, which is explained
- A key store or a database

## What you will need

- A JDK is optional: Gradle finds or downloads JDK 25 by itself. Everything else comes with the Gradle wrapper.
- About an hour for the session guide.
