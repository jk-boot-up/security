Beginner: Foundations (Java)

One self-contained project per concept, in Java 25 with Gradle. Each project has runnable code with deterministic tests, a README, diagrams, a step-by-step animation, a session guide and a narrated video. Every project runs on your own machine, with no cloud account.

Follow the learning path for the exact order of every project. The modules, in order:

Module Projects built Covers
foundations 2 the CIA triad, threats and risk
identity 2 authentication and authorization
passwords-and-mfa 6 password hashing, password attacks, one-time codes
cryptography 8 hashing, encryption, signatures
networking 7 TCP/IP, DNS, HTTP
transport-security 7 the TLS handshake, certificates, HTTPS
safe-habits 7 least privilege, patching, backups

All seven modules exist, with 39 projects. The full plan is in ../../docs/beginner-plan.md.

Run a project

cd foundations/cia-triad
./gradlew test
./gradlew run

Gradle finds or downloads JDK 25 by itself. If Gradle cannot find a JDK 25 you installed, point it at one with -Dorg.gradle.java.installations.paths=/path/to/jdk-25.

Build a project's docs, video and animation

tools/conceptkit/conceptkit.sh build cia-triad

This reruns the tests and regenerates the docs, diagrams, thumbnail, video, animation narration and the HTML pages from the project's concept.toml. Videos and audio are build output and are not committed. It needs Python 3, ffmpeg and Node. Nothing is uploaded.
