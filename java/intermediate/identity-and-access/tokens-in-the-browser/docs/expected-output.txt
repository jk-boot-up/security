== 1. A token in local storage ==
the app calls the API with its token      -> 200 balance of ana: 125000 cents

== 2. One injected script takes the token away ==
what the injected script can read         -> [localStorage.access_token]
the attacker's own computer uses it       -> 200 balance of ana: 125000 cents  <- NO KEY, NO PAGE, STILL WORKS

== 3. A backend for the frontend keeps the token ==
what the injected script can read         -> []
the page calls the BFF with its cookie    -> 200 balance of ana: 125000 cents
the attacker's computer with no cookie    -> 401 not signed in
a form post from evil.example (cookie)    -> 403 cross-site request refused
the script rides the session in the page  -> 200 balance of ana: 125000 cents  <- WHILE THE PAGE IS OPEN
after sign-out, the same cookie           -> 401 not signed in

== 4. A token that needs the key as well (DPoP) ==
the app: token + a proof from its key     -> 200 balance of ana: 125000 cents
the same proof sent again (replay)        -> 401 proof already used
the stolen token as a bearer token        -> 401 this token needs a proof of possession
the stolen token, no proof                -> 401 not a JWT
the stolen token, a proof from their key  -> 401 proof was signed with another key
a proof meant for a transfer              -> 401 proof is for another method
a proof saved for later                   -> 401 proof is too old or from the future
a fresh proof from the real key           -> 200 balance of ana: 125000 cents
