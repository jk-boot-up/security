== 1. Signing in through the bank ==
trusting provider, genuine response    -> signed in as ana@bank.example
strict provider, genuine response      -> signed in as ana@bank.example

== 2. A valid signature is not the same as the bank's signature ==
trusting provider, self-signed         -> signed in as admin@bank.example
pinned-key provider, self-signed       -> refused: signature is not valid
pinned-key provider, edited name       -> refused: signature is not valid

== 3. A valid signature on one assertion, and another one read ==
pinned-key provider, wrapped           -> signed in as admin@bank.example
strict provider, wrapped               -> refused: exactly one assertion is required
strict provider, self-signed           -> refused: signature is not valid
strict provider, edited name           -> refused: signature is not valid

== 4. The statement itself is checked ==
genuine response, first time           -> signed in as ana@bank.example
the same response replayed             -> refused: assertion already used
expired assertion                      -> refused: assertion is outside its validity period
meant for another shop                 -> refused: assertion is for another audience
answers another request                -> refused: assertion answers another request
response with a DOCTYPE                -> refused: not well-formed XML or has a DOCTYPE
