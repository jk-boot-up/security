# Problem Statement

## The scenario

An online store on Spring Boot with Actuator for health checks, where a developer wants to look inside a running store and finds a setting that shows everything.

## The naive version

Expose every endpoint, show every value, and turn on the switches the tutorial asks for.

## What this project must deliver

- Real Spring Boot stores in five configurations.
- A checker with eight checks that never changes the store.
- A heap dump search that finds a payment key in memory.
- A hardened store with its own port, a short list, login rules and read-only access.
