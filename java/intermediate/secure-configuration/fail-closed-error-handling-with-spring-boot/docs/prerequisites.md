# Prerequisites

## Required

- Java basics
- The plain fail-closed-error-handling project, for the idea

## Explicitly not required

- A real payment provider: the fraud service is a few lines of Java
- A database server: the ledger is in memory

## What you will need

- A JDK is optional: Gradle finds or downloads JDK 25 by itself. Everything else comes with the Gradle wrapper.
- About an hour for the session guide.
