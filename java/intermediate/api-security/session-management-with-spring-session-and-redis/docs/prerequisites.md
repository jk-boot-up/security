# Prerequisites

## Required

- Java basics
- The plain session-management project, for the rules
- Docker, with the redis:8.10.2-alpine image (pulled on first use)

## Explicitly not required

- A Redis server installed on the machine: the demo starts and removes its own container

## What you will need

- A JDK is optional: Gradle finds or downloads JDK 25 by itself. Everything else comes with the Gradle wrapper.
- docker
- About an hour for the session guide.
