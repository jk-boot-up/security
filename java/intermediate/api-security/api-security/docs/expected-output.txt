== 1. A profile call that works ==
PATCH displayName            -> 200 fields [displayName, email, role, balanceCents, creditLimitCents, riskScore, cardNumber, pinHash], role=customer, creditLimitCents=50000

== 2. Whatever the caller sends becomes a field ==
PATCH role, creditLimit      -> 200 fields [displayName, email, role, balanceCents, creditLimitCents, riskScore, cardNumber, pinHash], role=admin, creditLimitCents=100000000  <- NOT HERS TO CHANGE

== 3. The response is the whole record, and a list has no end ==
GET /accounts/acc-0001       -> 200 fields [displayName, email, role, balanceCents, creditLimitCents, riskScore, cardNumber, pinHash], role=admin, creditLimitCents=100000000
GET /accounts?size=1000000   -> 200 300 accounts, every field  <- EVERY CUSTOMER
1000 requests in a loop      -> 1000 answered, none slowed down

== 4. Explicit models, a page cap and a budget ==
PATCH displayName            -> 200 fields [id, displayName, email, balanceCents, cardLast4], card ****0001
PATCH role, creditLimit      -> 400 unknown field
role afterwards              -> customer
GET /accounts/acc-0001       -> 200 fields [id, displayName, email, balanceCents, cardLast4], card ****0001
GET /accounts?size=1000000   -> 200 50 accounts, id and name only

== 5. The budget runs out, and refills ==
1000 requests in a loop      -> 49 answered, then 429 with Retry-After 1s
after waiting that long      -> 200 fields [id, displayName, email, balanceCents, cardLast4], card ****0001
another customer meanwhile   -> 200 5 accounts, id and name only
