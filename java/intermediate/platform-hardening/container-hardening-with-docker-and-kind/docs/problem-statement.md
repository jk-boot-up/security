# Problem Statement

## The scenario

An online store runs its application in a container, and a vulnerability in the application may one day give an attacker a shell in it.

## The naive version

Copy the docker run line from a tutorial, because it works.

## What this project must deliver

- Thirteen real attempts run inside real containers.
- A step-by-step reduction from 13 to 1.
- A real kind cluster that refuses pods by standard.
- The attacks that remain, and why.
