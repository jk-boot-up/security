== 2. Hibernate does not stop a quote ==
jpql search "zzz' or p.listed = false or p.name like 'zzz" -> [Prototype Toaster]
jpql guess that a hash starts pbkdf2$ana -> [Blue Kettle, Copper Pan, Prototype Toaster, Red Kettle]

native search "zzz' union select email || ' ' || password_hash from users --" -> [ana@shop.example pbkdf2$ana$9f2c, ben@shop.example pbkdf2$ben$41d0]

== 3. Parameters keep text as text, in JPQL, native SQL and Criteria ==
jpql search 'Kettle' -> [Blue Kettle, Red Kettle]
jpql search "zzz' or p.listed = false or p.name like 'zzz" -> [no results]
jpql guess that a hash starts pbkdf2$ana -> [no results]
native search "zzz' union select email || ' ' || password_hash from users --" -> [no results]
criteria search "zzz' or p.listed = false or p.name like 'zzz" -> [no results]
sort "price; drop table products" -> [Blue Kettle, Red Kettle]
