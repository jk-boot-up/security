# Prerequisites

## Required

- Java basics
- The plain project broken-access-control, or what IDOR, horizontal and vertical escalation mean

## Explicitly not required

- Earlier Spring experience: the configuration is small and explained
- A database: orders are kept in memory, looked up the way a Spring Data repository would

## What you will need

- A JDK is optional: Gradle finds or downloads JDK 25 by itself. Everything else comes with the Gradle wrapper.
- About an hour for the session guide.
