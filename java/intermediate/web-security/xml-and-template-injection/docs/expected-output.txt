== 4. A template engine that evaluates expressions ==
the owner's template            -> Hello Ana, your order shipped.
name pasted into the template   -> Hello demo-smtp-password, your order shipped.
class name of the customer      -> com.jk.explore.security.xmlinj.Customer
name passed as data             -> Hello ${app.config.smtpPassword}

== 5. A logic-less engine keeps data as data ==
the owner's template            -> Hello Ana, your order shipped.

a name with markup              -> Hello &lt;script&gt;x&lt;/script&gt;
