== 1. The search page works for honest customers ==
search 'kettle' -> [Blue Kettle, Red Kettle]

== 2. A quote turns the customer's text into SQL ==
search "zzz' OR listed = 0 --" -> [Prototype Toaster]
search "zzz' UNION SELECT email, password_hash FROM users --" -> [ana@shop.example, ben@shop.example]
sort "price; DROP TABLE products" -> refused: unexpected ';' (one statement only)

== 3. Parameters keep text as text ==
search 'kettle' -> [Blue Kettle, Red Kettle]
search "zzz' OR listed = 0 --" -> [no results]
search "zzz' UNION SELECT email, password_hash FROM users --" -> [no results]
sort "price; DROP TABLE products" -> [Blue Kettle, Red Kettle]

== 4. A database user with few rights limits the damage of a mistake ==
search "zzz' UNION SELECT email, password_hash FROM users --" -> refused: permission denied for table users
