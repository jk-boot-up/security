  HOW b, 2852039166, BECOMES AN ADDRESS:
    2852039166 / 16777216 = 169, remainder 16689662
    16689662 / 65536 = 254, remainder 43518
    43518 / 256 = 169, remainder 254
    -> 169.254.169.254 (Java reads it the same)
  HOW c, 127.1, BECOMES AN ADDRESS:
    2 parts given, 2 missing
    the last number, 1, fills the last 3 parts
    -> 127.0.0.1 (Java reads it the same)
  HOW d, ::ffff:a9fe:a9fe, BECOMES AN ADDRESS:
    ::ffff: means an IPv4 address follows
    a9fe: hex a9 = 169, hex fe = 254
    a9fe: hex a9 = 169, hex fe = 254
    -> 169.254.169.254 (Java reads it the same)
  HOW e AND f GET INSIDE:
    look up intranet.attacker.example: 10.0.0.5
    GET /go at attacker.example: 302, go to 169.254.169.254
