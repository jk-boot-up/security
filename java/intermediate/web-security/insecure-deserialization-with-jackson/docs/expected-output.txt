== 1. A cart in a cookie ==
cart round trip                       -> 2 lines, total 9200 cents

== 2. The cookie decides which class is built ==
an Object field                       -> refused (the default validator denies class names for an Object)
forged price                          -> 1 lines, total 2 cents
cookie holds a TempCleaner            -> accepted as a note; marker file exists afterwards: false
global default typing, TempCleaner    -> accepted as a note; marker file exists afterwards: false

== 3. A list of kinds, or a list of classes ==
names: cart round trip                -> 2 lines, total 9200 cents
names: cookie holds a TempCleaner     -> refused (unknown type id); marker file exists afterwards: true
validator: cart round trip            -> 2 lines, total 9200 cents
validator: cookie holds a TempCleaner -> refused (class not allowed); marker file exists afterwards: true
forged price                          -> 1 lines, total 2 cents  <- STILL ACCEPTED

== 4. Data only: names and quantities, priced by the shop ==
order round trip                      -> 2 items, total 9200 cents
forged price                          -> refused (unknown property price)
a class name                          -> refused (unknown property @class)
quantity -5                           -> refused (quantity must be 1 to 99)
unknown product                       -> refused (unknown product)

== 5. Limits on the stream ==
default limits, 5000 levels deep      -> refused (nesting deeper than 500)
tightened, 11 levels deep             -> refused (nesting deeper than 10)
tightened, a 65 character product     -> refused (text longer than 64)
tightened, an 11 digit quantity       -> refused (number longer than 10)
