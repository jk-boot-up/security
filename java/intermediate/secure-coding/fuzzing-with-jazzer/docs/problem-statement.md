# Problem Statement

## The scenario

An online store parses order lines and carts from outside, and its example tests pass.

## The naive version

Write more example tests until it feels safe.

## What this project must deliver

- The real Jazzer on two parsers, with a fixed random seed.
- The effect of seeds and of coverage.
- Minimal inputs as regression tests.
- A sanitizer finding, and the limits of fuzzing.
