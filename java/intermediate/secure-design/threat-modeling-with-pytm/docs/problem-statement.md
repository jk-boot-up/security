# Problem Statement

## The scenario

A bank is designed by several teams, and nobody has asked systematically what could go wrong at each element and flow.

## The naive version

Draw a picture and write down the threats that come to mind.

## What this project must deliver

- The bank's design as a pytm model, written by a program.
- 113 threats checked against every element and flow.
- The effect of each honest answer.
- A diagram and a report from the same model.
