# Problem Statement

## The scenario

A bank has an attack tree and abuse cases, and wants its threat model reviewed in a diagram where the threats sit on the flows and processes they concern.

## The naive version

Draw the diagram by hand and type the threats in.

## What this project must deliver

- A Threat Dragon model file written from the attack tree.
- Validation by the editor's own schema and validator.
- The plan applied to the file.
- Rules for what a schema cannot check.
