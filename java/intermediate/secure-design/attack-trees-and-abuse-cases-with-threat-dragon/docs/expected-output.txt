TWO. From the tree's numbers to a severity.
  THE INPUT: THE TREE'S STEPS FOR AC1 (AND: ALL ARE NEEDED)
    A1a    300 EUR  90%  build a phishing page that relays the code
    A1b     50 EUR  20%  she enters the password and the code
  HOW THE SCORE IS WORKED OUT:
    cost      300 + 50 = 350 EUR   (costs add up)
    chance    90% x 20% = 18%   (chances multiply)
    severity  High, because cost <= 500 EUR
  THE SEVERITY RULE:
    High      cost <= 500 EUR or chance >= 50%
    Medium    cost <= 5,000 EUR
    Low       cost > 5,000 EUR
  THE RESULT: ALL 8 CASES, SCORED
