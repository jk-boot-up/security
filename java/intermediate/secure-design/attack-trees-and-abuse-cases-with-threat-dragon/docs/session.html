Session Guide — Attack Trees and Abuse Cases in Threat Dragon

Learning Objectives

By the end of the session you can:

  • read a Threat Dragon model file
  • place a threat on the element or flow it hits
  • validate a model file with the editor's validator
  • say what a model file cannot hold

Timetable

Walkthrough

Run act two and read the four messages. In act three compare the open threats with the failing abuse cases. In act four find the rule that catches a stale flag.

Exercises

  1. Open the model in the editor and move a flow; see what changes in the file.
  2. Add a second diagram for the approval console and write its threats.
  3. Add a rule that every High threat has a score.
  4. Write the diff of two steps of the plan and read it as a reviewer.
