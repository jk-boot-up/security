== 1. The tree ==
OR: Move money out of Ana's account
  OR: Log in as Ana
    AND: Phish her password and one-time code
      - [A1a] build a phishing page that relays the code  (300 EUR, 90%)
      - [A1b] she enters the password and the code  (50 EUR, 20%)
    AND: Reuse a leaked password
      - [A2a] buy a list of leaked passwords  (100 EUR, 80%)
      - [A2b] she reuses one, and nothing else is asked  (0 EUR, 15%)
    AND: SIM swap
      - [A3a] talk the phone company into a new SIM  (1,500 EUR, 30%)
      - [A3b] know or guess her password  (100 EUR, 15%)
    AND: Steal her session with a script
      - [A4a] find a stored script injection in the memo field  (2,000 EUR, 10%)
      - [A4b] she opens the page while signed in  (0 EUR, 50%)
  OR: Abuse the transfer call
    - [B1] change the account number in the request to Ana's  (50 EUR, 90%)
    AND: Forge a request from another site
      - [B2a] lure Ana to a page with a hidden form  (100 EUR, 50%)
      - [B2b] the bank accepts a request with only her cookie  (0 EUR, 95%)
  - [C] bribe an employee who can approve transfers  (20,000 EUR, 20%)
  AND: Break in through the software
    - [D1] exploit a known flaw in an unpatched library  (5,000 EUR, 15%)
    - [D2] move from the web server to the database  (1,000 EUR, 60%)
