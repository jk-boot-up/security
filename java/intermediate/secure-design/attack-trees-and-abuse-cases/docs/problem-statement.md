# Problem Statement

## The scenario

An online bank has a list of threats and a budget that covers some of them. The team must decide which defences to build first.

## The naive version

Build the defence that sounds strongest or is in the news this month.

## What this project must deliver

- An attack tree with AND and OR gates, costs and chances, and an analysis of the cheapest path and the success chance.
- Eight defences with prices and their effects on the leaves.
- A planner that cuts the cheapest path and recomputes.
- Eight abuse cases as executable checks against a model of the bank's configuration.
