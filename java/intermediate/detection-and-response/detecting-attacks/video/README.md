# Detecting Attacks in Logs — Teaching Video

A narrated, slide-based video built by `./build_video.sh` with the shared videokit library.

| File | What it is |
| --- | --- |
| `detecting-attacks-explained.mp4` | the video, 1920×1080 |
| `detecting-attacks-explained.m4a` | audio only |
| `detecting-attacks-explained.srt` | subtitles |
| `poster.png` | the opening frame |

**Narration:** Piper `en_US-amy-medium`, speed 0.8, longer pauses (the amy-slow voice). Scenes are generated from `../concept.toml` into `scenes.py`.

Suggested description:

> Detection rules over a log stream in Java: brute force, password spraying, impossible travel, takeover and privilege change, with precision measured against a synthetic day.
