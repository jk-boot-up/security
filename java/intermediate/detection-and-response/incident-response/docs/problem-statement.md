# Problem Statement

## The scenario

The shop's web server is breached at night. The team on duty has to decide in minutes what to do, with partial information.

## The naive version

Find the server that was hacked, turn it off and on again, change the password and move on.

## What this project must deliver

- A simulated incident with a scripted attacker, three footholds and a data theft in progress.
- A preparation checklist and a responder whose actions have durations and effects.
- Three responses (panic, improvised, playbook) and a review table.
- The NIST lifecycle mapped onto concrete actions: contain, capture, scope, eradicate, recover, learn.
