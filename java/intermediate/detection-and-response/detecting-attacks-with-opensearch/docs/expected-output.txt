FIVE. The bill.
  the same events loaded with no mapping, grouped by user: 400, Text fields are not optimised for operations that require per-document field data like aggregations and sorting, so these operations are disabled by default. Please use a keyword field instead. ...
  grouped by user.keyword, which dynamic mapping adds next to the text: 200, 3 groups  <- A MAPPING DECIDES WHAT A RULE CAN SAY
  thirty failures in four minutes that cross a five-minute boundary at 13:30, rule 'at least 20': fixed buckets 0 alerts, a sliding window 1  <- THE ATTACK FALLS BETWEEN TWO BUCKETS
  the monitors run on a schedule, so an attack is noticed up to a minute and a bucket later, and a schedule that stops, or a query that is changed in the console, leaves no trace in the code
  keep the queries as files under version control and load them with the API, test each with a known bad day, and treat the thresholds as tuned for this one Monday
