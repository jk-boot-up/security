# Problem Statement

## The scenario

An online store has an audit log and four attacks hidden in one day of it, and wants alerts that a person can trust.

## The naive version

Read the log, or alert on every failed login.

## What this project must deliver

- A real OpenSearch with the alerting plugin.
- Detections as queries and as monitors.
- Tuning and scoring against known attacks.
- The detection a query cannot say.
