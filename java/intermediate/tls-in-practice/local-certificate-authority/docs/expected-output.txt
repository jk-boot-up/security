== 1. Issue a certificate and trust the root ==
root: subject=CN=Demo Root CA, self-signed, valid 3650 days
leaf: subject=CN=shop.example, issuer=CN=Demo Root CA, serial 1000, valid 90 days
names in the certificate -> [shop.example, *.shop.example]
connect to shop.example                    -> accepted

== 2. What a client refuses ==
connect to www.shop.example (wildcard)     -> accepted
connect to a.b.shop.example                -> refused: name a.b.shop.example is not in the certificate
connect to evil.example                    -> refused: name evil.example is not in the certificate
100 days later (expired)                   -> refused: certificate expired
issued by another authority                -> refused: not issued by a trusted authority
claims our CA, signed by another key       -> refused: signature does not match the issuer
a self-signed server certificate           -> refused: not issued by a trusted authority
a leaf that signs another certificate      -> refused: a certificate in the chain may not sign certificates

== 3. Revocation ==
the key is stolen on day 10; the CA revokes serial 1000 and publishes list number 2
with the new list                          -> refused: certificate revoked
with the list from day 0 (a stale one)     -> refused: revocation status unknown (no current list)
with no list at all                        -> refused: revocation status unknown (no current list)
with the new list, but it is 2 days old    -> refused: revocation status unknown (no current list)

== 4. Renewal ==
serial 1000 renewed as serial 1001, same key: true
old certificate on day 100                 -> refused: certificate expired
renewed certificate on day 100             -> accepted

== 5. Short-lived certificates instead of revocation ==
revocation: the stolen key is usable until clients fetch a new list, up to 24 hours after the theft is noticed
8-hour certificates: the stolen key stops working after at most 8 hours, with no list to fetch
short-lived certificate, now               -> accepted
short-lived certificate, 9 hours later     -> refused: certificate expired
