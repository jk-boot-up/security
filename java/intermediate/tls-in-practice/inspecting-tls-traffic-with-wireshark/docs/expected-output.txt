TWO. A key log: the secrets of one connection.
THE INPUT (openssl s_client -keylogfile keys.log):
  5 lines, as a browser writes with SSLKEYLOGFILE set
THE KEY LOG (each label, and what its secret opens):
  CLIENT_HANDSHAKE_TRAFFIC_SECRET  the client's handshake
  SERVER_HANDSHAKE_TRAFFIC_SECRET  the server's handshake

  SERVER_TRAFFIC_SECRET_0          the server's data
  EXPORTER_SECRET                  no traffic
ONE LINE, TAKEN APART:
  label          CLIENT_TRAFFIC_SECRET_0
  client random  32 bytes (64 hex digits)

THE SECRET'S SIZE, WORKED OUT (from the suite's hash):

THE MATCH, BY HAND (whose connection is it?):

  a private key in the file       no
