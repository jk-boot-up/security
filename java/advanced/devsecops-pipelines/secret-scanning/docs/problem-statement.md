# Problem Statement

## The scenario

A bank's team has committed keys over the years and wants to find them and stop the next one.

## The naive version

Delete the file and hope that nobody looks at the history.

## What this project must deliver

- A repository with planted secrets and look-alikes.
- A scanner written in Java and gitleaks, compared with the truth.
- An allowlist and a baseline.
- A pre-commit hook and a pre-receive hook.
