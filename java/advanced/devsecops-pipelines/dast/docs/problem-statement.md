# Problem Statement

## The scenario

A bank wants to know what an attacker can do to its running web application, before one does.

## The naive version

Run one scan without a login and call the report clean.

## What this project must deliver

- A running application with planted flaws.
- A passive, an anonymous and a logged-in scan counted against the truth.
- A rescan of the fixed version.
- A ZAP automation plan generated from Java.
