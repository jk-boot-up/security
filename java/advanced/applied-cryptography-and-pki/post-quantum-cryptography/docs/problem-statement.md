# Problem Statement

## The scenario

A bank must decide which of its data a future quantum computer could open from recordings made today, and what to change first.

## The naive version

Wait for the threat to be real, then replace RSA with a bigger RSA key.

## What this project must deliver

- ML-KEM and ML-DSA used from the JDK.
- A hybrid exchange with X25519.
- Sizes measured, not quoted.
- A model of harvest now, decrypt later.
- An inventory of where the old algorithms are.
