# Problem Statement

## The scenario

A vendor wants to know how easily its desktop client can be read and changed by a customer.

## The naive version

Rename the classes and hope that is enough.

## What this project must deliver

- A small client compiled in the demo.
- The constant pool, names and bytecode read with the JDK and javap.
- A decompiler and a patch of the licence check.
- The same on an obfuscated copy.
