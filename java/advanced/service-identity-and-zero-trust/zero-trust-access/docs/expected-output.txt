--- the bill
the proxy is the one door: the ledger turns away anything without its mark, and a mark in a flat network is a weak link; production wants mutual TLS between proxy and ledger
a token stays valid until it expires: a short lifetime and a session check shrink that window, and each costs a refresh or a call per request
Keycloak and OPA are on the path of every request; the proxy fails closed when OPA is gone, and keeps serving old tokens when Keycloak is gone
the device posture here is a claim the demo sets per client; a real one comes from a device management system and is only as good as it
no Envoy and no oauth2-proxy was run: the proxy is a small Java program so that every step shows, and either of them would do the same job in front of a real ledger
