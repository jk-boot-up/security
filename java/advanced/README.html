Advanced: Specialized Topics (Java)

One self-contained Java 25 + Gradle project per concept, as in the beginner and intermediate tracks. This track moves from one application to systems: platforms, pipelines, service identity, detection at scale, cryptographic change, and how security is run and governed. Everything runs on one laptop with no cloud account.
