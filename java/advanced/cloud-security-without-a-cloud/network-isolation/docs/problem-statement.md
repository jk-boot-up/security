# Problem Statement

## The scenario

An online store runs six services, one of which faces the internet, and one of them will one day be taken over.

## The naive version

Put everything on one network and rely on each service's own login.

## What this project must deliver

- Real networks and containers.
- Measurement from inside, by name and by address.
- The design as a table of allowed pairs, and a layout built from it.
- Drift found by comparing the measurement with the design.
