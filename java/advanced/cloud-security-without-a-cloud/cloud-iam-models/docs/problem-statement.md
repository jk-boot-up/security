# Problem Statement

## The scenario

A bank runs on a cloud with several accounts, a third-party reporting service and many policies written over time by different people.

## The naive version

Give people broad permissions and hope that nobody misuses them.

## What this project must deliver

- An evaluator for the policy language, following the documented rules.
- The effect of accounts, roles, boundaries and session policies.
- The confused deputy attack and its two defences.
- A search for paths to administrator rights.
