# Problem Statement

## The scenario

A bank moves its statements, exports and audit log to the cloud and gives its developers an account.

## The naive version

Click through the console until it works, and open whatever is in the way.

## What this project must deliver

- A real SDK against an emulator.
- Nine rules and a scan before and after the fixes.
- Checkov and Trivy on the same setup as files.
- The metadata service attacked and defended.
