# Problem Statement

## The scenario

A bank is preparing for an audit and needs to show what each control is, who owns it and whether it works today.

## The naive version

Fill in a spreadsheet the week before the audit.

## What this project must deliver

- A control catalogue with owners.
- Maps to NIST CSF 2.0 and to ISO 27001 Annex A.
- Evidence read from test results and attestations, with freshness rules.
- A status for each control and a trail an auditor can follow.
