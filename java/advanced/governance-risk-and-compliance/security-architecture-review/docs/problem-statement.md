# Problem Statement

## The scenario

A bank wants to find the weaknesses in a design before the system is built.

## The naive version

Hold a review meeting and write the comments in the margin of a PDF.

## What this project must deliver

- A design written in the Structurizr DSL.
- Rules over zones, flows, data stores, owners and decisions.
- Planted weaknesses to score the rules.
- A reviewed design and its decision records.
