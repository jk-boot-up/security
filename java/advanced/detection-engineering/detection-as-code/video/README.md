# Detection as Code — Teaching Video

A narrated, slide-based video built by `./build_video.sh` with the shared videokit library.

| File | What it is |
| --- | --- |
| `detection-as-code-explained.mp4` | the video, 1920×1080 |
| `detection-as-code-explained.m4a` | audio only |
| `detection-as-code-explained.srt` | subtitles |
| `poster.png` | the opening frame |

**Narration:** Piper `en_US-amy-medium`, speed 0.8, longer pauses (the amy-slow voice). Scenes are generated from `../concept.toml` into `scenes.py`.

Suggested description:

> Detection engineering for a bank: Sigma rules tagged with MITRE ATT&CK, tested against labelled logs, held to false-positive budgets, mutation tested, and converted by pySigma to OpenSearch queries.
