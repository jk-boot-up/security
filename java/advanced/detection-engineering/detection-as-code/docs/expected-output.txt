--- the bill
a rule is a hypothesis: the attacks it was written for are caught, the ones spelled another way are missed, and only a labelled corpus says how many
a filter that removes a false alarm is also a hole an attacker can use, so each one needs a test that says why it is there
a budget turns noise into a number: a rule over budget gets a filter or a higher threshold, or it is read by nobody
a threshold or a filter chosen on one week of logs fits that week: the next week is the test
covering a technique with a tag is not detecting it: coverage is what the labelled attacks show
