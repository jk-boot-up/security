# Problem Statement

## The scenario

A bank's team suspects that someone is already inside, and the alerts say nothing.

## The naive version

Wait for the alert, and search for the IP address from the last news article.

## What this project must deliver

- A seeded week of lookups, process starts and logins.
- Four hypotheses written as queries.
- Leads judged against what really happened.
- The hunt that worked turned into a rule.
